# PitchVision Studio

AI-Powered Football Pitch Keypoint Detection, Homography Transformation & Tactical Tactical Analytics.

## Overview
PitchVision Studio combines deep learning models (RepViT, SimCC, Keypoint Detectors) and 2D Planar Homography to project live match broadcast feeds into tactical 2D radar representations.

## Structure
- `backend/`: FastAPI backend and computer vision pipeline.
- `frontend/`: React + Vite interactive dashboard.
